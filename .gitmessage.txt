# 1. HEADER: <type>(<scope>): <subject>
#    - type:  See allowed types below.

#    - subject: Imperative, lowercase, no dot at end (e.g., "add login", not "Added login.").

#      feat(auth): add refresh token support
#      fix(chat): handle socket reconnection

#
# --- ALLOWED TYPES ---
#   feat     - A new feature (triggers MINOR release)
#   fix      - A bug fix (triggers PATCH release)
#   perf     - Performance improvement (triggers PATCH release)
#   revert   - Reverts a previous commit
#   docs     - Documentation only
#   style    - White-space, formatting, missing semi-colons, etc
#   refactor - A code change that neither fixes a bug nor adds a feature
#   test     - Adding missing tests or correcting existing tests
#   build    - Changes that affect the build system (npm, maven, gradle)
#   chore    - Other changes that don't modify src or test files
#   ci       - Changes to CI configuration files and scripts
